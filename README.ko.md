# MacHelper

[English](README.md) · [繁體中文](README.zh-Hant.md) · [简体中文](README.zh-Hans.md) · [日本語](README.ja.md) · 한국어 · [Español](README.es.md)

macOS 14 이상을 위한 올인원 Mac 유틸리티로, 모든 데이터가 Mac 안에만 머뭅니다. 팬 제어, 메뉴 막대 시스템 모니터, 원클릭 정리, 디스크 분석, 앱 제거, 시동 항목 관리를 제공합니다. MIT 라이선스 오픈 소스입니다.

## 기능

- **메뉴 막대 모니터**: CPU(성능 코어와 효율 코어), GPU, 메모리 압력, 디스크 및 네트워크 속도, 온도, 팬, 전력, 배터리. 각 항목을 텍스트, 선, 막대, 링으로 표시할 수 있습니다. CPU와 메모리를 가장 많이 쓰는 프로세스도 보여 줍니다.
- **기록**: 1분마다 평균값을 기록하며 기본적으로 7일 동안 보관합니다. 설정 → 일반 → 데이터 관리에서 1, 3, 7, 14, 30일 중에 고를 수 있습니다. 최근 1시간, 24시간, 7일을 볼 수 있습니다.
- **선택 사항인 프로세스·센서·코어 기록**: 기본적으로 꺼져 있으며 설정 → 일반 → 데이터 관리에서 각각 켭니다. 프로세스 기록에는 프로세스 이름과 CPU 및 메모리 사용량만 남기며 경로, 명령줄 인수, 사용자 이름은 기록하지 않습니다. 매분 CPU와 메모리 상위 10개만 보관합니다.
- **알림**: CPU 온도가 높거나, 메모리 압력이 위험하거나, 디스크 공간이 부족하면 알려 줍니다.
- **팬 제어**: 자동, 고정 속도, 온도 곡선(조용함, 균형, 성능, 사용자 지정), ‘증가만’ 모드, 안전 한도, 실행 중인 앱이나 전원에 따른 프로필 자동 전환. 호출자의 서명을 확인하는 root Helper를 통해 작동합니다.
- **원클릭 최적화**: 미리 본 다음 정리합니다. 낮은 위험의 캐시와 로그는 바로 삭제하고 중간 및 높은 위험 항목은 휴지통으로 옮깁니다. 보호 경로, 정리 제외 목록, 작업 기록, 유지 관리 작업, 프로젝트 빌드 산출물 정리, 낮은 위험 항목의 예약 자동 정리를 지원합니다.
- **디스크 분석**: 선버스트와 트리맵, 종류와 기간으로 거를 수 있는 큰 파일, 중복 파일(APFS 복제본과 하드 링크 구분), 지난 스캔 이후의 변화, 한 번에 휴지통으로 옮기는 수집함.
- **공간 제안**: 반년 넘게 쓰지 않은 큰 파일과 비대해 보이는 폴더를 찾아 차트에 표시합니다.
- **앱 제거**: 번들 ID, 내장 도우미, 권한, 컨테이너 정보, launchd 소유자, Homebrew zap 목록, 앱별 규칙으로 앱이 남긴 것을 찾습니다. 이름으로만 일치한 항목은 확인하도록 표시합니다. 이미 지운 앱의 잔여 파일도 찾습니다.
- **시동 항목**: 내 Launch Agent(비활성화, 활성화, 제거), 모든 사용자의 Agent, 시스템 Daemon. 소속 앱과 깨진 항목을 표시합니다.
- **Homebrew 업데이트**: Homebrew로 설치한 앱을 업데이트합니다.
- **자동 업데이트**: 새 버전을 백그라운드에서 확인하고 다운로드한 뒤 설치 전에 묻습니다.
- **보안 점검**: Gatekeeper, FileVault, 방화벽, 시스템 무결성 보호, 자동 보안 업데이트, XProtect 상태를 읽습니다(읽기만 하며 변경하지 않음).
- **명령줄 도구**: 자동화와 AI 에이전트를 위해 모든 기능을 명령으로 쓸 수 있습니다. 기본적으로 미리 보기만 하며 모든 명령이 `--json`을 지원합니다. 개요는 `machelper guide`, 각 명령 설명은 `machelper <명령> --help`로 확인합니다.
- **AI 에이전트 스킬**: Claude Code와 Codex에 스킬을 추가해 MacHelper를 안전하게 쓰게 할 수 있습니다. 항상 먼저 미리 보고, 제거하기 전에 묻습니다.
- **언어**: 영어, 번체 중국어, 간체 중국어, 일본어, 한국어, 스페인어. 설정 → 일반 → 언어에서 시스템과 다른 언어를 고를 수 있습니다.

## 설치

[Releases](https://github.com/smile-minecraft/MacHelper/releases)에서 `MacHelper-<버전>.dmg`를 내려받아 MacHelper를 응용 프로그램 폴더로 드래그하십시오. Homebrew로도 설치할 수 있습니다:

```sh
brew install --cask smile-minecraft/tap/machelper
```

MacHelper는 Developer ID로 서명되고 Apple의 공증을 받았으므로 다른 앱처럼 바로 열 수 있습니다. 팬 제어와 시스템 정리에는 Helper가 필요합니다. MacHelper가 요청하면 **시스템 설정 → 일반 → 로그인 항목**에서 허용하십시오.

디스크 전체를 보려면 **시스템 설정 → 개인정보 보호 및 보안 → 전체 디스크 접근 권한**에서 MacHelper를 켜십시오. 켜더라도 시스템 무결성 보호 대상이나 다른 사용자의 폴더는 읽을 수 없습니다. 이는 macOS의 보호 기능이며 정상입니다.

각 버전의 다운로드 파일 체크섬은 릴리스 페이지의 `SHA256SUMS.txt`에 있습니다.

## 소스에서 빌드

Xcode 16 이상과 [XcodeGen](https://github.com/yonaskolb/XcodeGen)이 필요합니다.

```sh
xcodegen generate
scripts/install.sh          # Release 빌드 → /Applications/MacHelper.app, 그다음 다시 실행
swift test                  # Swift 패키지 단위 테스트
```

서명, 프로젝트 구조, 릴리스 절차, 번역 방법은 [영어 README](README.md)를 참고하십시오.
