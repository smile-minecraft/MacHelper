MacHelper 现在会告诉你有新版本，不再悄悄自动安装；更新说明会用你的语言显示，菜单栏项目也终于能完整显示。

### 更新
- 后台检查到新版本时，侧边栏、菜单栏面板和设置页会出现「更新到 x.y.z」按钮。点按后会显示更新内容并安装；没有你的同意不会安装任何东西。
- 检查频率从每天一次改为每四小时一次。
- 更新窗口会用 MacHelper 当前的语言显示更新说明（英文、繁体中文、简体中文、日文、韩文或西班牙文）。
- 0.3.0 和 0.3.1 每次启动都会打开「自动安装」，这个版本会把它关闭一次。

### 修复
- 菜单栏项目不会再卡在启动时的宽度、让数值两侧被截断。现在只要项目、样式、标签或字体改变，就会重新测量宽度。
