MacHelper 現在會告訴你有新版本，不再默默自動安裝；更新說明會用你的語言顯示，選單列項目也終於能完整顯示。

### 更新
- 背景檢查到新版本時，側邊欄、選單列面板和設定頁會出現「更新到 x.y.z」按鈕。按下後會顯示更新內容並安裝；沒有你的同意不會安裝任何東西。
- 檢查頻率從每天一次改成每四小時一次。
- 更新視窗會用 MacHelper 目前的語言顯示更新說明（英文、繁體中文、簡體中文、日文、韓文或西班牙文）。
- 0.3.0 和 0.3.1 每次啟動都會開啟「自動安裝」，這個版本會把它關掉一次。

### 修正
- 選單列項目不會再卡在啟動時的寬度、讓數值兩側被切掉。現在只要項目、樣式、標籤或字型改變，就會重新量測寬度。
- 磁碟分析：側欄的分頁（內容、最大檔案、重複、變化、建議）在英文等較長的語言會被切掉。側欄稍微加寬，名稱仍放不下時，分頁會改成顯示完整名稱的選單。

### 文件
- 全新的 README，加上史萊姆動畫和實際介面截圖，六種語言都已更新。
