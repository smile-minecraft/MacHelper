ページは前回の結果をすぐ表示し、ファンのプリセットは階段状のカーブになり、Homebrew アップデートに MacHelper 自身が表示されなくなりました。

### 速度
- ヘルスチェックは前回のレポートをすぐ表示し、バックグラウンドで更新します。初回の読み込みは約 718 ms から 60 ms に、1 時間・24 時間・7 日の切り替えは初回以降 1–2 ms になります。
- ディスク分析で開いたことのある場所に戻る時間は 818 ms から約 0.2 ms、アンインストールの再表示は 683 ms から 114 ms、起動項目は 199 ms から 27 ms になりました。
- キャッシュは上限付きです：ヘルスレポート（3 期間・60 秒）、セキュリティ（5 分）、ディスクツリー（2 棵、ページを離れると現在の場所だけ）、ボリューム情報（8 か所・60 秒）、App リスト（2 分）、起動項目（1 分）、センサーとプロセス履歴（6／4 組・1 分）。
- メモリは起動時と 6 ページを見た後で同じ水準です。ディスクページは同じ時点で約 245 MB になり、以前の 654 MB より少なくなりました。

### ファン
- Quiet、Balanced、Performance は階段状のカーブになりました。数度の間は同じ回転数を保ち、そこから上がります。どの温度でも Quiet ≤ Balanced ≤ Performance です。
- 既存のカスタムカーブは変更しません。古いプリセットは「カスタム」と表示され、プリセットを選び直すと新しいカーブが適用されます。
- 自動切り替えは Helper の一時的な失敗や復帰後に再試行します。

### Homebrew アップデート
- MacHelper は自分の Homebrew アップデート一覧に表示されなくなりました。「自動更新する App を含める」がオンでも表示されません。実行中の App をインストールした cask を認識するため、古い cask バージョンでダウングレードを提示することもありません。
- ページを開き直すと前回の一覧をすぐ表示し、バックグラウンドで更新します。

### UI と修正
- 最適化のフィルターバーは狭いウィンドウでは 2 行になります。Never Clean シートは内容に合わせて高さが変わり、合計は右揃えになり、未選択時に「0 maintenance tasks」と表示されません。
- ファンの回転数は大きな文字でも切れなくなりました。エラーメッセージはホバーまたは選択で全文を確認でき、制御できないファンで内部の strategy 文字列を表示しなくなりました。
- チェックボックスとアイコンボタンに VoiceOver ラベルを追加しました。ヘルスページの CPU 説明は CPU リストの下に残り、列は大きな文字でも切れません。
- 新しい文字列に繁体字中国語を追加しました。
