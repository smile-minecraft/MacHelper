페이지는 이전 결과를 먼저 보여 주고, 팬 프리셋은 계단형 곡선이 되며, Homebrew 업데이트에 MacHelper 자신이 더 이상 표시되지 않습니다.

### 속도
- 건강 검사는 이전 보고서를 먼저 보여 주고 백그라운드에서 새로 고칩니다. 첫 로드는 약 718 ms에서 60 ms로, 1시간·24시간·7일 전환은 첫 번째 이후 1–2 ms로 줄었습니다.
- 디스크 분석에서 열었던 위치로 돌아가는 시간은 818 ms에서 약 0.2 ms로, 앱 제거 화면 재진입은 683 ms에서 114 ms로, 시작 항목은 199 ms에서 27 ms로 줄었습니다.
- 캐시에는 모두 상한이 있습니다: 건강 보고서(3개 기간·60초), 보안 검사(5분), 디스크 트리(2개, 페이지를 떠나면 현재 위치만), 볼륨 정보(8개 위치·60초), 앱 목록(2분), 시작 항목(1분), 센서·프로세스 기록(6/4개·1분).
- 메모리는 실행 직후와 여섯 페이지를 본 뒤에도 같은 수준입니다. 디스크 페이지는 같은 시점에 약 245 MB로, 이전의 654 MB보다 낮습니다.

### 팬
- Quiet, Balanced, Performance가 계단형 곡선이 되었습니다. 몇 도 동안 같은 속도를 유지한 뒤 올라갑니다. 모든 온도에서 Quiet ≤ Balanced ≤ Performance입니다.
- 기존 사용자 지정 곡선은 건드리지 않습니다. 이전 프리셋은 '사용자 지정'으로 표시되며, 프리셋을 다시 선택하면 새 곡선이 적용됩니다.
- 자동 전환은 Helper가 잠시 실패하거나 다시 사용 가능해지면 재시도합니다.

### Homebrew 업데이트
- MacHelper는 자체 Homebrew 업데이트 목록에 더 이상 표시되지 않습니다. '스스로 업데이트하는 앱 포함'이 켜져 있어도 마찬가지입니다. 실행 중인 앱을 설치한 cask를 인식하므로 오래된 cask 버전으로 다운그레이드를 제안하지 않습니다.
- 페이지를 다시 열면 이전 목록을 먼저 보여 주고 백그라운드에서 새로 고칩니다.

### UI 및 수정
- 최적화 필터 바는 좁은 창에서 두 줄이 됩니다. Never Clean 시트는 내용에 맞춰 높이가 변하고, 합계는 오른쪽 정렬되며, 아무것도 선택하지 않았을 때 '0 maintenance tasks'를 표시하지 않습니다.
- 팬 속도 값은 큰 글자에서도 잘리지 않습니다. 오류 메시지는 마우스를 올리거나 선택해 전체를 볼 수 있고, 제어할 수 없는 팬에서 내부 strategy 문자열을 표시하지 않습니다.
- 체크박스와 아이콘 버튼에 VoiceOver 레이블을 추가했습니다. 건강 페이지의 CPU 설명은 CPU 목록 아래에 남고, 열은 큰 글자에서도 잘리지 않습니다.
- 새 문자열에 번체 중국어를 추가했습니다.
