메뉴 막대의 네트워크 페이지를 중요한 숫자가 바로 보이도록 새로 만들었습니다. 새 전력 페이지에서는 전력이 어디에 쓰이는지 보여 주며, 팬도 같은 페이지로 합쳤습니다.

### 네트워크
- 맨 위 연결 카드에 Wi‑Fi 또는 이더넷, 신호 강도와 등급, 링크 속도, IP 주소를 표시합니다.
- 다운로드와 업로드는 각각 큰 카드로 현재 속도, 5분 최고치, 작은 추이 그래프를 보여 줍니다.
- 트래픽 그래프는 5분, 1시간, 24시간으로 전환할 수 있고, 포인터 위치의 시각과 두 속도를 표시합니다.
- ‘앱별 트래픽’은 네트워크를 쓰는 앱과 다운로드·업로드 속도, 비율을 보여 주며 현재·다운로드·업로드·누적 순으로 정렬할 수 있습니다. 도우미 프로세스는 해당 앱에 합산합니다. 수치는 이 페이지가 열려 있을 때만 `nettop` 스냅숏에서 읽습니다.

### 전력
- 새 전력 탭은 전체 전력과 항목별로 색을 나눈 막대 하나, 항목별 행(CPU, GPU, Neural Engine, 메모리 중 이 Mac이 보고하는 것)을 보여 줍니다. 칩 전원 레일로 측정되지 않는 부분은 ‘시스템 기타’ 하나로 묶고, 부품별 숫자를 지어내지 않습니다.
- 전력 추이는 5분 범위에서 전체·CPU·GPU를, 1시간과 24시간에서는 기록된 전체 전력을 표시합니다.

### 팬
- 팬이 전력 페이지로 옮겨졌습니다. 최고 온도를 보여 주는 온도계, 팬 속도, CPU·GPU·SSD 온도, 그리고 팬 속도와 CPU 온도를 두 축으로 함께 그린 그래프가 있습니다.
- 자동, 조용히, 균형, 성능을 메뉴 막대에서 바로 고를 수 있고, 현재 모드가 강조 표시됩니다. ‘사용자 설정…’은 팬 제어를 엽니다.

### 메뉴 막대
- 탭이 다섯 개를 넘으면 아이콘을 글자 위에 두어 모든 탭이 들어가게 했습니다.
- SSD와 네트워크 인터페이스 아래의 설명 문구를 없앴습니다.

### 언어
- 새 문구를 여섯 개 언어로 모두 번역했습니다.
