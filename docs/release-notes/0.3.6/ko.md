메뉴 막대의 배터리 페이지에 연결된 액세서리의 충전량이 표시되고, 패널 페이지는 순서를 바꾸거나 끌 수 있습니다. 디스크 분석의 최대 파일 목록은 필터를 조합할 수 있고, 스캔 합계를 볼륨 사용량과 대조해 설명하며, 로컬 스냅샷을 보여 줍니다. SSD 페이지에는 어떤 앱이 디스크를 읽고 쓰는지 나타납니다. 정리에는 Claude Code, Codex, OpenCode 규칙이 추가되었으며, 자동 정리는 30분마다 실행할 수 있고 만료된 임시 파일도 정리할 수 있습니다.

### 배터리
- 내장 배터리 아래에 연결된 액세서리가 함께 표시되며, Bluetooth 장치(Magic Keyboard, 마우스, 트랙패드, AirPods 등), USB로 충전량을 보고하는 장치, 무선 수신기를 통해 연결된 Logitech 장치를 지원합니다. 각 행에 충전량과 게이지, 충전 중 표시가 있고 AirPods은 왼쪽·오른쪽·충전 케이스를 따로 보여 줍니다. 충전이 가장 적은 것이 맨 위에 옵니다.
- 유선과 수신기 장치는 해당 장치가 원래 지원하는 배터리 프로토콜로 백그라운드에서 조회합니다. 페어링이나 설치를 하지 않고 입력을 가로채지도 않습니다.

### 메뉴 막대
- 설정의 메뉴 막대 페이지에서 패널의 모든 페이지를 나열하고 켜기/끄기와 위·아래 버튼으로 표시할 페이지와 순서를 정할 수 있습니다. 마지막으로 표시된 페이지는 끌 수 없고, 하드웨어가 없는 페이지는 자동으로 숨겨집니다.

### 디스크 분석
- 최대 파일 목록은 파일 이름이나 전체 경로 검색, 최소 크기, 종류(동영상, 이미지, 오디오, 압축 파일, 디스크 이미지, 앱, 문서, 개발 파일, 기타), 경과 기간('90일 동안 수정 없음' 등)을 조합해 필터링할 수 있습니다. 설정한 조건을 모두 만족해야 하며, '필터 지우기'로 전체 목록으로 돌아갑니다.
- 볼륨 전체를 스캔하면 결과가 실제 사용량 중 스캔이 측정한 비중을 함께 알려 주며, 나머지는 시스템 데이터나 다른 APFS 볼륨과 공유하는 공간이라서 지울 수 있는 용량이 아니라고 밝힙니다. 스캔 합계가 볼륨 보고보다 크면 스캔 중 파일이 바뀌었음을 알리고, 폴더 하나만 스캔했을 때는 볼륨 전체와 비교할 수 없다고 표시합니다.
- 로컬 APFS와 Time Machine 스냅샷을 만든 시각과 함께 보여 줍니다. 스냅샷은 볼륨과 공간을 공유하고 macOS가 관리하므로 읽기 전용 목록으로만 제공하고, 크기를 추정하거나 삭제를 제안하지 않습니다.

### SSD
- 새 '앱별 디스크 I/O'가 커널이 각 앱의 프로세스별로 집계한 읽기·쓰기 양을 순위로 보여 줍니다. 행마다 읽기·쓰기 속도와 비율을 표시하고 상위 6개 행만 나열하며 나머지는 한 행으로 합칩니다. 수치는 프로세스 I/O 카운터로 실제 디스크 처리량이 아니며 화면에도 그렇게 적혀 있습니다. 현재 사용자가 조회할 수 없는 프로세스(다른 사용자나 시스템)는 0으로 표시하지 않고 각주에 개수만 남기며, 샘플링은 SSD 페이지가 열려 있을 때만 합니다.

### 정리
- Claude Code, Codex, OpenCode 규칙을 추가했습니다. 낮은 위험 파일(캐시, 1주일 넘은 로그, 임시 파일)은 기본으로 정리됩니다. 각 에이전트의 세션 기록(Claude Code 대화 기록, Codex 세션, OpenCode 도구 출력)은 목록에만 표시하고 기본 선택에서는 제외하며, 한 달이 지나야 휴지통으로 옮깁니다. 규칙은 에이전트 프로그램 본체, 설치된 플러그인, 설정, 자격 증명을 건드리지 않습니다. 에이전트가 실행 중이면 해당 규칙은 멈추고(삭제 직전에 매번 확인), 미리 보기 뒤에 바뀐 파일(다시 시작한 세션이 이어서 쓴 파일 등)은 그대로 둡니다.

### 자동 정리
- 새 간격으로 30분마다, 매시간, 3시간마다를 추가했습니다(매일·매주는 기존대로). 백그라운드 에이전트는 30분마다 확인하고 설정한 간격이 되었을 때만 실행합니다. 기존 일정은 자동으로 이전됩니다. 이전이 중단되거나 실패하면 다음 새로 고침 때 다시 시도되고, 실패는 다시 시도 버튼과 함께 알립니다.
- '만료된 임시 파일 정리'는 기본 꺼짐입니다. 켜면 임시 폴더에서 7일 이상 변경되지 않았고 사용 중이 아닌 항목을 예정된 정리 때마다 제거합니다. '삭제하지 않고 휴지통으로 이동' 설정에 따라 휴지통으로 옮기거나 바로 삭제합니다. 시스템이 직접 관리하는 항목과 사용 중·기록 중인 파일은 건너뜁니다.
