選單列的電池頁現在也顯示已連線配件的電量，面板的分頁也能調整順序或關閉顯示。磁碟分析的最大檔案清單可以組合篩選條件，掃描總量會說明與卷宗已用空間的差額，並列出本機快照；SSD 頁顯示哪些 App 正在讀寫磁碟，清理新增 Claude Code、Codex 和 OpenCode 的規則。自動清理可以每 30 分鐘執行，也能開啟過期暫存檔清理。

### 電池
- 內建電池下方列出已連線的配件：藍牙裝置（Magic Keyboard、滑鼠、觸控式軌跡板或 AirPods 等）、透過 USB 回報電量的裝置，以及透過無線接收器連線的羅技裝置。每一列顯示電量、電量條和充電標示，AirPods 另外列出左耳、右耳和充電盒，電量最少的排在最前面。
- 有線和接收器裝置的電量，是用裝置本身支援的協定在背景查詢的；不配對、不安裝任何東西，也不攔截輸入。

### 選單列
- 設定 → 選單列列出面板的每個分頁，附開關和上下按鈕：分頁要不要顯示、先後順序都可以自己決定。最後一個顯示中的分頁不能關閉，沒有對應硬體的分頁會自動隱藏。

### 磁碟分析
- 最大檔案清單的篩選條件可以組合：依名稱或完整路徑搜尋、大小下限、檔案類型（影片、圖片、音訊、封存檔、磁碟映像檔、應用程式、文件、開發者檔案、其他）和修改時間（例如 90 天未修改）。所有條件同時符合的檔案才會顯示；「清除篩選」會回到完整清單。
- 掃描整個卷宗之後，掃描結果涵蓋了卷宗已用空間的多少，其餘屬於系統資料或與其他 APFS 卷宗共用的空間，無法靠清理釋放。掃描量比卷宗回報的多時，會說明掃描期間檔案有變動；只掃單一資料夾時，會說明總量不能和整個卷宗比較。
- 本機 APFS 與 Time Machine 快照會連同拍攝時間列出。快照和卷宗共用空間、由 macOS 管理，所以只提供唯讀清單，不推估大小，也不提供刪除。

### SSD
- 新的「依 App 顯示的磁碟 I/O」區塊，依系統核心統計各 App 程序的讀寫量排序，顯示讀寫速率和佔比；最忙碌的六列在前，其餘合併成一列。數字是程序的 I/O 計數，不是實體磁碟吞吐量，畫面上也會標明。目前帳號沒有權限讀取的程序（其他使用者或系統程序）不會顯示成 0，而是在註腳計數。取樣只在 SSD 頁開啟時進行。

### 清理
- 新增 Claude Code、Codex 和 OpenCode 的清理規則。低風險檔案（快取、超過一週的日誌和暫存檔）預設會清理。各代理的對話記錄（Claude Code 對話記錄、Codex 對話記錄、OpenCode 工具輸出）只會列出供選擇、不預設勾選，而且超過一個月才會搬進垃圾桶。規則不會動到代理本身的程式、已安裝的外掛、設定或憑證。代理正在執行時，對應規則會暫停（每次刪除前重新檢查）；預覽之後有變動的檔案（例如繼續先前的對話而寫入新內容）會保持原狀。

### 自動清理
- 新增頻率：每 30 分鐘、每小時和每 3 小時，和原本的每天、每週並列。背景代理程式改為每 30 分鐘檢查一次，只在排程到期時執行。既有的排程會自動遷移；遷移中斷或失敗時，下次重新整理會再試一次，失敗也會顯示重試按鈕。
- 「清理過期的暫存檔案」預設關閉。開啟後，暫存檔案夾裡至少 7 天沒有使用、沒有變動的檔案和資料夾，會在每次排程清理後，依「改為移到垃圾桶，不直接刪除」的設定移進垃圾桶或直接刪除。系統自己管理的項目，以及使用中或還在寫入的檔案，都會跳過。
