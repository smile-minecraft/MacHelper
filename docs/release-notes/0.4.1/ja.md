MacHelper のライトモードと Liquid Glass における視認性を大幅に改善し、初回起動時の個別シートを 1 つの「ようこそガイド」に統合しました。さらに Sparkle や手動 DMG アップデート時の Helper の信頼性を高め、AI エージェント向けの匿名化診断レポート（`machelper report`）や、デフォルトオフのプライバシー重視テレメトリと開発者向けプロファイリングを追加しています。

### テーマとサーフェスマテリアル
- **設定 → 外観** で **外観**（`システム` / `ライト` / `ダーク`）と **マテリアル**（`ソリッド` / `フロスト`〔新しいデフォルト〕 / `Liquid Glass`）を統合しました。アクセシビリティに応じた自動フォールバックにも対応しています（「透明度を下げる」がオンの場合はソリッド、macOS 26 未満・ピクセルスタイル・「コントラストを上げる」がオンの場合は Liquid Glass からフロストへ切り替わります）。
- ライトモードで Liquid Glass を使用した際のメニューバーパネルの視認性を修正しました。選択中のタブピル、終了ボタン、カード、チップ、アイコンボタン、グラフの軸、淡色ラベル（コントラスト比 4.5:1）、および未着色テキストが、明るい壁紙でも暗い壁紙でも色が飛んだり文字色が混在したりせずくっきり表示されます。
- サーフェス全体でセマンティックなコントラストトークンを導入し、カスタムテーマやインポートした VS Code テーマ向けのコントラスト安全ネットを追加しました（ビルトインテーマの色味は維持されます）。
- **設定 → 外観** を刷新し、ライト／ダーク／システムおよびマテリアルのピッカー、フォールバックの説明、ライト／ダークのプレビュー・極性・コントラスト検証結果を示すテーマカードを備えました。

### ようこそガイド
- 初回起動時に別々に開いていた 3 つのシート（フルディスクアクセス、Helper、エージェントスキル）を、環境設定・メニューバー案内・任意の権限・AI エージェントスキルをまとめた 6 ステップの対話型 **ようこそガイド** に統合しました。
- **ヘルプ → ようこそガイド…** からいつでも再生できます。旧バージョンのオンボーディングをすでに完了したユーザーにはアップデート後に再表示されません。

### Helper の信頼性と復旧
- Sparkle によるアップデート時のシームレスな引き継ぎと手動 DMG アップデートの検出を追加し、App 入れ替え後も Helper の状態を引き継げるようにしました。
- 登録状態の確認だけでなく実際の XPC 応答チェックによるライブ監視を行い、安全な障害に対しては非破壊的な自動復旧を実行します。
- Helper の対応が必要なときは、ワンクリックの **Helper を修復**・**ログイン項目を開く** ボタンを備えたわかりやすいアプリ内警告バナー、正確なサイドバー状態表示、および重複しないローカル通知で案内します。

### AI エージェント CLI
- ワンショットで匿名化された Mac 全体の診断レポートを出力する `machelper report`（`--json` / `--format markdown`）を追加しました。ユーザー名、ホームパス、ホスト名、IP／MAC アドレス、外付けボリューム名はデフォルトで自動的にマスクされます。
- JSON レポートに構造化された `suggestedActions` と `availableTools` を追加し、`machelper guide --json` を導入、ビルトインのエージェントスキルを v3 にアップグレードしました。

### プライバシーとパフォーマンス
- **設定 → 一般 → プライバシーと診断** にオプトインの匿名利用統計と粗粒度のパフォーマンス診断（**デフォルトでオフ**）を追加しました。個人情報やファイルパスは一切含まず、送信前の JSON サンプルペイロードのプレビューに対応し、オフにすると匿名 ID と送信待ちキューを即座に消去します。
- 主要パスにネイティブの `OSSignposter` 計装を追加し、開発者向けの計測スクリプト `scripts/perf/xctrace-profile.sh` を用意しました。

### ドキュメントと Web サイト
- 6 言語の README を刷新し、`make screenshots` を使って架空のデモデータによるスクリーンショットへ差し替え、GitHub Pages サイトを全面的にリニューアルしました。
