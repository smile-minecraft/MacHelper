MacHelper가 라이트 모드와 Liquid Glass 환경에서의 가독성을 다듬고, 나뉘어 있던 첫 실행 안내 창을 하나의 ‘환영 가이드’로 통합했으며, Sparkle 및 수동 DMG 업데이트 전반에서 Helper 안정성을 강화했습니다. 또한 AI 에이전트를 위한 비식별화 진단 리포트(`machelper report`)와 기본 꺼짐 상태의 익명 진단·개발자 프로파일링 도구를 추가했습니다.

### 테마 및 표면 재질
- **설정 → 모양**에서 **모양**(`시스템` / `라이트` / `다크`)과 **재질**(`불투명` / `반투명`〔새 기본값〕 / `Liquid Glass`)을 통합하고 접근성 자동 폴백을 적용했습니다(투명도 줄이기 활성화 시 불투명 사용, 이전 macOS·픽셀 스타일·대비 증가 시 Liquid Glass 대신 반투명 사용).
- 라이트 모드 Liquid Glass에서 메뉴 막대 패널의 가독성을 바로잡았습니다. 선택된 탭 알약, 종료 버튼, 카드, 칩, 아이콘 버튼, 차트 축, 옅은 라벨(4.5:1 대비), 기본 텍스트가 밝은 배경화면과 어두운 배경화면 모두에서 흐려지거나 글자 색이 섞이지 않고 또렷하게 보입니다.
- 모든 표면에 시맨틱 대비 토큰을 도입하고 사용자 지정·가져온 VS Code 테마를 위한 대비 안전망을 추가했습니다(내장 테마 색상은 그대로 유지됩니다).
- **설정 → 모양**을 새롭게 구성해 라이트·다크·시스템 및 재질 선택기, 폴백 안내, 라이트/다크 미리 보기·명암 극성·대비 점검 결과를 보여 주는 테마 카드를 제공합니다.

### 환영 가이드
- 처음 실행 시 따로 열리던 세 개의 시트(전체 디스크 접근 권한, Helper, 에이전트 스킬)를 기본 설정, 메뉴 막대 둘러보기, 선택적 권한, AI 에이전트 스킬을 아우르는 6단계 대화형 **환영 가이드**로 통합했습니다.
- **도움말 → 환영 가이드…**에서 언제든 다시 볼 수 있으며, 이전 온보딩을 이미 마친 사용자에게는 업데이트 후 다시 표시되지 않습니다.

### Helper 안정성 및 복구
- 앱 교체 후에도 Helper 상태를 이어갈 수 있도록 매끄러운 Sparkle 업데이트 인계와 수동 DMG 업데이트 감지를 추가했습니다.
- 단순 등록 상태 확인 대신 실제 XPC 응답을 검증하는 실시간 상태 모니터링과 안전한 오류에 대한 비파괴 자동 복구를 도입했습니다.
- Helper 조치가 필요할 때 원클릭 **Helper 복구** 및 **로그인 항목 열기** 버튼을 갖춘 명확한 앱 내 경고 배너, 정확한 사이드바 상태 표시, 중복 없는 로컬 알림을 제공합니다.

### AI 에이전트 CLI
- 한 번의 호출로 비식별화된 전체 Mac 진단 리포트를 생성하는 `machelper report`(`--json` / `--format markdown`)를 추가했습니다. 사용자 이름, 홈 경로, 호스트 이름, IP·MAC 주소, 외장 볼륨 이름은 기본적으로 자동 가려집니다.
- JSON 리포트에 구조화된 `suggestedActions`와 `availableTools`를 추가하고 `machelper guide --json`을 제공하며, 내장 에이전트 스킬을 v3로 업그레이드했습니다.

### 개인정보 보호 및 성능
- **설정 → 일반 → 개인 정보 및 진단**에 선택적 익명 사용 통계 및 거친 성능 진단(**기본값 꺼짐**)을 추가했습니다. 개인정보나 파일 경로를 전혀 수집하지 않으며, JSON 샘플 페이로드를 미리 볼 수 있고, 끄는 즉시 익명 ID와 대기 중인 큐가 삭제됩니다.
- 주요 경로에 네이티브 `OSSignposter` 계측과 개발자 프로파일링용 `scripts/perf/xctrace-profile.sh` 스크립트를 추가했습니다.
