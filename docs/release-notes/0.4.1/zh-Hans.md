MacHelper 进一步优化了浅色模式与液态玻璃的界面对比度与可读性，将原本分散的首次启动弹窗整合为统一的「欢迎导览」，并增强了 Helper 在 Sparkle 与手动 DMG 更新时的稳定性。AI Agent 现可通过 `machelper report` 一次获取完整的脱敏诊断报告，同时加入了默认关闭的匿名诊断与开发者性能剖析工具。

### 主题与表面材质
- 在 **设置 → 外观** 中统一了 **外观**（`跟随系统` / `浅色` / `深色`）与 **材质**（`实色` / `磨砂`〔新默认〕 / `液态玻璃`），并支持辅助功能自动回退（开启“降低透明度”时使用实色；在较早版本的 macOS、像素风格或开启“增强对比度”时，液态玻璃会自动回退为磨砂）。
- 修复了浅色模式下菜单栏面板开启液态玻璃时的可读性问题：选中标签胶囊、退出按钮、卡片、徽章、图标按钮、图表坐标轴、浅色标签（达到 4.5:1 对比度）以及默认文字在浅色与深色壁纸上均保持清晰，不再泛白或混用深浅字色。
- 新增跨表面语义对比度令牌，并为自定义及导入的 VS Code 主题提供对比度兜底校验，同时保持内置主题原有配色不变。
- 重新设计了 **设置 → 外观**，提供浅色／深色／系统与材质选择器、回退说明，以及展示浅／深色预览、明暗极性与对比度审计结果的主题卡片。

### 欢迎导览
- 将原本三个独立的首次启动弹窗（完全磁盘访问权限、Helper 与 Agent 技能）整合为 6 步交互式 **欢迎导览**，涵盖偏好设置、菜单栏导览、可选权限与 AI Agent 技能。
- 可随时通过 **帮助 → 欢迎导览…** 重新播放；此前已看过旧版引导的用户在升级后不会再次弹出。

### Helper 稳定性与恢复
- 新增无缝 Sparkle 更新交接与手动 DMG 更新检测，确保替换应用后 Helper 状态能够顺利延续。
- 以真实 XPC 存活验证替代仅检查注册状态，并对安全故障自动执行非破坏性恢复。
- 当 Helper 需要处理时，应用内会显示清晰的警告横幅，并提供一键 **修复 Helper** 与 **打开登录项** 按钮、准确的侧边栏状态提示以及去重的本地通知。

### AI Agent 命令行
- 新增 `machelper report`（支持 `--json` / `--format markdown`），一次生成脱敏的整机诊断报告，默认自动抹除用户名、主目录路径、主机名、IP 与 MAC 地址以及外接宗卷名称。
- 在 JSON 报告中加入结构化的 `suggestedActions` 与 `availableTools`，新增 `machelper guide --json`，并将内置 Agent 技能升级至 v3。

### 隐私与性能
- 在 **设置 → 通用 → 隐私与诊断** 中新增可选的匿名使用统计与粗粒度性能诊断（**默认关闭**），零个人身份信息与文件路径，支持在设置内直接预览 JSON 示例载荷，关闭后立即清除匿名 ID 与待发送队列。
- 在热路径中加入原生 `OSSignposter` 埋点，并提供 `scripts/perf/xctrace-profile.sh` 供开发者进行性能剖析。

### 文档与网站
- 全面改版六种语言的 README，通过 `make screenshots` 改用合成示例数据重绘截图，并重新设计了 GitHub Pages 官网。
