MacHelper に管理者認証付きの **ディープ最適化** を追加し、**設定 → 機能** で各ツールモジュールのオン／オフ切り替えに対応しました。さらに **ニューモーフィズム**（`ソフト`）外観と **ソフトクレイ** テーマを導入し、設定画面の切り替えアニメーションを滑らかにしつつメニューバーの CPU 負荷を低く保っています。

### ディープ最適化
- **最適化** の **スキャンを開始** の下に **ディープ最適化…** を追加しました。root 権限が必要なシステムキャッシュ、ローテーション／圧縮済みログ、診断レポート、シミュレータキャッシュ、1 週間以上経過した一時ファイルをスキャンして削除できます。
- 対象フォルダと一致ルールはすべて Helper 側に固定されています（アプリは対象 ID のみを送信）。スキャンとプレビューにパスワードは不要で、削除の実行時のみ毎回管理者パスワードまたは Touch ID を求めます。中リスク項目はデフォルトでオフになっています。
- シンボリックリンク、ハードリンク、Apple 純正システムキャッシュ、および保護・変更不可・追記のみ・Data Vault・SIP フラグが付いた項目はスキップします。APFS／Time Machine スナップショット、SIP 保護ファイル、統合ログには一切触れません。
- 新しい Helper（プロトコル v7）が必要です。未設定または古いバージョンの場合は **ディープ最適化…** が無効になり、**Helper を設定または修復…** のリンクが表示されます。

### 機能モジュール
- **設定 → 機能** タブを追加し、8 つのツール（**モニタ**、**ヘルスチェック**、**ファン**、**最適化**、**ディスク分析**、**アンインストール**、**Homebrew アップデート**、**起動項目**）を個別に切り替えられるようにしました。**概要** は常に表示され、すべてのモジュールは初期状態でオンのため、アップデート直後の画面は変わりません。
- オフにしたツールはサイドバー、`⌘1`–`⌘9` のメニューショートカット（残る項目の番号はそのまま維持）、メニューバーのクイックバー、**概要** のショートカットから非表示になります。開いていたページをオフにした場合は **概要** に戻ります。
- 無効にしたモジュールのバックグラウンド処理は、保存済みの設定を消さずに停止します。**モニタ** はバックグラウンド記録エージェントを解除し、**最適化** は定期クリーンアップを停止し、**ファン** はポーリングを止めてシステム自動制御へ戻し、**Homebrew アップデート** は更新確認を停止します。**モニタ** と **最適化** は再びオンにすると元のスケジュール設定が復元され、**ファン** は手動で戻すまで自動制御のままになります。
- 手動ポリシーやルールが有効な **ファン**、または定期クリーンアップがオンの **最適化** をオフにする前には確認ダイアログを表示します。シンプルモードは引き続き機能し、設定のバックアップにオン／オフ状態が含まれます（以前のバックアップも読み込み可能）。機能が無効なとき、**最適化** と **ヘルスチェック** の **ショートカット** アクションは機能がオフである旨を返します。

### ニューモーフィズムテーマ
- **設定 → 外観** に **ソフト** 形状、ビルトインの **ソフトクレイ**（`builtin.soft`）ライト／ダークテーマ、および **ニューモーフィズム** プリセットを追加しました。
- カードやコントロールは背景から浮き上がり、トラックや溝は凹んで見え、ボタンは押すと浮き上がりから押し込みへと変化します。左上からのやわらかな光と影をくっきり保つため、**ソフト** 形状では **マテリアル** が **ソリッド** に固定されます。

### モーションとアニメーション
- **設定** 画面でオプションを切り替えた際に注記や条件付き行が 1 フレームで切り替わる不具合を修正し、安定したビュー ID とクロスフェードによる共通トランジションに統一しました。**視差効果を減らす** がオンのときは移動を省きフェードのみになります。
- アプリ全体のアニメーション呼び出し箇所を点検して **視差効果を減らす** への準拠を確認し、メニューバーパネルの毎秒の数値更新における数字ロール遷移を削除して CPU 負荷を抑えました。
