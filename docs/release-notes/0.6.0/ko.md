MacHelper에 USB-C 포트 사양과 충전 진단, 연결된 기기를 확인하는 읽기 전용 **케이블** 페이지를 추가하고, Finder·Dock·창·단축키·Mission Control을 제어하는 **조정** 페이지와 CLI 명령을 도입했습니다. **심층 최적화**에서는 삭제를 시작하기 전에 먼저 관리자 인증을 받도록 흐름을 바꿨습니다.

### 케이블
- **이 Mac** 그룹에 Helper 없이 동작하는 읽기 전용 **케이블**(`⌘U`) 페이지를 추가했습니다. **설정 → 기능**에서 끌 수 있습니다.
- 각 USB-C 및 Thunderbolt 포트에 연결된 케이블의 e-marker 정보를 읽어 데이터 속도, 최대 전류, 지원 전압, **EPR** 지원 여부, **액티브 케이블**/**패시브 케이블** 구분, 지연 시간을 표시합니다.
- 충전이 느리거나 연결 속도가 떨어지는 원인을 진단합니다. 정격보다 낮은 어댑터, 60 W로 제한되는 3 A 또는 e-marker 없는 케이블, macOS `NotChargingReason`에 따른 충전 일시 중지, 허브·디스플레이를 통한 전력 공급, 배터리 과열, USB 2.0 속도로 연결된 USB 3 기기를 찾아냅니다.
- Thunderbolt/USB4 기기, **USB 기기 트리**(허브와 협상된 링크 속도 포함), 연결된 **디스플레이**의 해상도·주사율·링크 속도를 보여줍니다.
- `machelper cable` 명령(`status`, `ports`, `devices`, `displays`, `charging` 하위 명령 및 `--json` 지원)을 추가했습니다.

### 조정
- **조정**(`⌘T`) 페이지를 추가했습니다. 설정은 `tweaks.json`에 저장되며(**설정 → 기능**에서 기본 켜짐), `machelper tweaks list|status|enable|disable|set|reset`(`--json` 지원) 명령으로도 바꿀 수 있습니다. 대부분 손쉬운 사용 권한이 필요합니다.
- **Finder**: **Finder에서 파일 잘라내기 및 붙여넣기**는 `⌘X` / `⌘V`로 파일을 이동하며, 텍스트 입력 칸에서는 가로채지 않고 선택한 항목이 없을 때는 동작하지 않습니다. **Finder에서 새 파일**(기본 단축키 `⌃⌥N` 변경 가능, Finder 자동화 권한 필요)은 **일반 텍스트**, **Markdown**, **서식 있는 텍스트**, **사용자 설정 확장자** 템플릿으로 파일을 만들고, 이름이 겹치면 번호를 붙인 뒤 바로 이름 변경 상태로 전환합니다. **Finder 상황에 맞는 메뉴 항목**(시스템 설정에서 MacHelper Finder 확장 활성화 필요)은 오른쪽 클릭 메뉴에 **새 파일**(템플릿 선택 포함), **경로 복사**, **터미널에서 열기**, **잘라내기**를 추가합니다. **Finder 열 너비 맞추기**는 Finder가 손쉬운 사용에서 열 너비 변경을 허용하지 않아 사용 불가로 표시됩니다.
- **Dock 및 미디어**: **Dock 아이콘 클릭 동작**으로 앞에 있는 앱의 Dock 아이콘을 클릭할 때 **앱 숨기기**, **창 최소화**, **창 순환** 중 원하는 동작을 실행합니다. **Music 자동 실행 차단**은 Music이 열리자마자 닫고, 원할 경우 대신 실행할 앱을 지정할 수 있습니다.
- **창 및 단축키**: **창 컨트롤 버튼**으로 닫기(**마지막 윈도우를 닫으면 앱 종료**), 최소화(**앱 숨기기**), 확대(**화면 채우기**(전체 화면 전환 없음) 또는 **시스템 확대/축소**) 버튼 동작을 바꿀 수 있습니다. `⌥` 키를 누른 채 클릭하거나 **제외할 앱 번들 ID**에 등록된 앱은 기본 macOS 동작을 유지합니다. **⌘Tab로 최소화된 창 복원**은 보이는 창이 없는 앱으로 전환할 때 마지막으로 최소화한 창을 다시 띄웁니다. **종료 단축키 보호**는 `⌘Q`(선택적으로 **⌘W도 보호**)를 **길게 누르기** 또는 **두 번 누르기**로 동작하게 하며, 앱별 제외를 지원합니다.
- **창 관리**: **메뉴 막대 창 목록**(**윈도우 목록**)은 열려 있거나 최소화된 창을 앱별로 묶어 보여주며 창마다 **보기**, **최소화**/**복원**, **닫기**를, 앱마다 **가리기**, **종료**를 실행할 수 있고 **전역 단축키**도 지정할 수 있습니다. **Mission Control 창 버튼**은 창 미리보기 위에 닫기·최소화 버튼을 덧붙입니다.
- `machelper windows list|focus|minimize|restore|close` 명령(`--json` 지원)을 추가했습니다.

### 심층 최적화
- **최적화**에서 **인증 후 정리…**를 누르면 일반 항목을 포함해 무엇이든 지우기 전에 먼저 관리자 암호 또는 Touch ID 인증을 요청합니다. 인증을 취소하면 전체 작업이 중단되어 아무 파일도 삭제되지 않습니다.
- 심층 정리 대상과 일반 항목을 함께 선택했을 때 미리 보기 막대에 **심층 정리만…** 버튼이 나타나 관리자 권한 정리만 따로 실행할 수 있습니다.
