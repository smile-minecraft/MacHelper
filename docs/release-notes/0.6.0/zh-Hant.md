MacHelper 新增唯讀的 **線材** 頁面來檢視 USB-C 連接埠規格、充電診斷與外接裝置，加入 **調整** 頁面提供 Finder、Dock、視窗、快捷鍵與 Mission Control 等操控選項及對應的 CLI 指令，並調整 **深層優化** 流程，在刪除任何檔案前就先要求管理員驗證。

### 線材
- 在 **這台 Mac** 群組下新增 **線材**（`⌘U`），全程唯讀且不需要 Helper；可在 **設定 → 功能** 中關閉。
- 針對每個 USB-C 與 Thunderbolt 埠讀取線材 e-marker 晶片回報的實際規格：傳輸速度、最大電流、支援電壓、**EPR** 擴展功率支援、**主動線材**／**被動線材** 類型與延遲。
- 診斷充電變慢與連線瓶頸：變壓器瓦數不足、3 A 或無 e-marker 線材將充電限制在 60 W、macOS `NotChargingReason` 充電暫停原因、透過 Hub 或螢幕供電、電池過熱，以及 USB 3 裝置降速跑在 USB 2.0。
- 列出 Thunderbolt／USB4 裝置、**USB 裝置樹**（含 Hub 與實際協商速度），以及外接 **螢幕** 的解析度、更新率與連線速率。
- 新增 `machelper cable` 指令（支援 `status`、`ports`、`devices`、`displays`、`charging` 子指令與 `--json`）。

### 調整
- 新增 **調整**（`⌘T`），所有開關與選項皆儲存在 `tweaks.json`（預設於 **設定 → 功能** 開啟），並搭配 `machelper tweaks list|status|enable|disable|set|reset`（支援 `--json`）。多數項目需要輔助使用權限。
- **Finder**：**在 Finder 中剪下與貼上檔案** 讓 `⌘X`／`⌘V` 直接移動檔案，在文字欄位內不會攔截，未選取任何項目時也不會觸發。**在 Finder 中新增檔案**（預設 `⌃⌥N`，可自訂；需開啟 Finder 自動化權限）支援 **純文字**、**Markdown**、**富文字** 與 **自訂副檔名** 範本，檔名重複時自動加上序號，建立後立即進入重新命名。**Finder 右鍵選單項目**（需先在系統設定啟用 MacHelper 的 Finder 擴充功能）會在右鍵選單加入 **新增檔案**（可選範本）、**拷貝路徑**、**在終端機中開啟** 與 **剪下**。**調整 Finder 欄寬** 因 Finder 不允許「輔助使用」設定欄寬而標示為無法使用。
- **Dock 與媒體**：**點擊 Dock 圖示的動作** 可在點擊前景 App 的 Dock 圖示時執行 **隱藏 App**、**最小化視窗** 或 **循環切換視窗**。**封鎖 Music 自動啟動** 會在 Music 啟動時立刻關閉，並可設定替代開啟的 App。
- **視窗與快捷鍵**：**紅綠燈按鈕** 可自訂紅燈（**關閉最後一個視窗時結束應用程式**）、黃燈（**隱藏 App**）與綠燈（**填滿螢幕** 而不進入全螢幕，或 **系統縮放**）的行為，按住 `⌥` 一律維持系統預設行為，也能設定 **排除的 App bundle id**。**用 ⌘Tab 還原最小化的視窗** 會在切換到沒有可見視窗的 App 時自動還原上一個最小化視窗。**結束快捷鍵防誤觸** 要求 **長按** 或 **連按兩次** `⌘Q`（可選 **也保護 ⌘W**）才生效，並支援排除特定 App。
- **視窗管理**：**選單列中的視窗清單**（**視窗列表**）依 App 分組列出開啟與最小化的視窗，每個視窗可 **顯示**、**縮到最小**／**還原** 或 **關閉**，每個 App 可 **隱藏** 或 **結束**，也能設定 **全域快速鍵**。**Mission Control 中的視窗按鈕** 會在縮圖上方加上關閉與最小化按鈕。
- 新增 `machelper windows list|focus|minimize|restore|close` 指令（支援 `--json`）。

### 深層優化
- 在 **一鍵優化** 按下 **驗證並清理…** 時，改為在刪除任何項目之前就先要求輸入管理員密碼或驗證 Touch ID；一旦取消就中止整次清理，不會先刪掉一般項目。
- 同時勾選深層清理與一般項目時，預覽操作列會顯示 **只執行深層優化…** 按鈕，可單獨執行需要管理員權限的清理。
