MacHelper에 Apple Silicon과 함께 Intel(`x86_64`) Mac을 기본 지원하는 유니버설 빌드를 추가하고, **소프트**(뉴모피즘) 테마와 **최적화** 화면 동선 및 로딩 부드러움을 다듬었습니다. 또한 **케이블**에서 M1 Pro/M1 Max 권장 어댑터 와트 수가 뒤바뀌어 있던 문제를 바로잡고, 앱 실행 중 허용한 손쉬운 사용 권한도 감지하도록 개선했습니다.

### 유니버설 Mac 지원
- 이제 macOS 14 이상에서 Apple Silicon과 Intel(`x86_64`) Mac 모두에서 네이티브로 동작하는 유니버설 앱으로 빌드되며, Homebrew cask도 더 이상 `arm64`를 요구하지 않습니다.
- Intel Mac에서는 온도와 팬 제어에 SMC를 사용하고 전체 시스템 전력도 SMC에서 읽어 옵니다(Apple Silicon 전용 전력 세부 항목은 제공되지 않습니다). `machelper status`와 `machelper report`에 SMC 온도가 표시되며, 듀얼 GPU 모델에서는 작업량이 가장 많은 활성 GPU를 보고합니다. 팬 제어 안전 상한은 Intel에 맞춰 보수적인 기준(95 °C / 88 °C)을 적용했고, **케이블**에는 Intel MacBook Pro 및 MacBook Air 모델의 권장 어댑터 와트 수를 추가했습니다.
- 실제 Intel Mac 하드웨어에서는 아직 검증하지 못했습니다. Intel 기기에서 하드웨어 관련 문제가 발생하면 제보해 주세요.

### 인터페이스 및 최적화
- **소프트**(뉴모피즘) 테마에서 메뉴 막대 패널 상단에 여백을 추가해 첫 번째 카드 왼쪽 위의 하이라이트가 탭 막대 아래로 잘리지 않도록 했으며, 다크 모드의 하이라이트와 그림자를 차분하게 줄이고 좁은 팬·전력 카드 사이 간격을 넓혔습니다.
- **최적화** 시작 화면에서 **스캔 시작**과 **심층 최적화…** 버튼을 같은 높이로 나란히 배치했습니다. **최적화** 도구 막대와 미리 보기·결과 막대에는 **메뉴로 돌아가기** 버튼을 추가해 다시 스캔하지 않고도 일반 최적화와 심층 최적화 사이를 오갈 수 있습니다.
- 스캔 전 확인 작업을 메인 스레드에서 분리하고 시스템 정리 미리 보기를 규칙 스캔과 함께 실행해 스캔 시작을 앞당겼으며, 진행률 업데이트 중에도 스캔 애니메이션이 끊기지 않고 부드럽게 이어집니다.

### 케이블
- 14형과 16형 M1 Pro/M1 Max MacBook Pro의 권장 어댑터 와트 수가 서로 바뀌어 있던 오류를 수정해(16형은 140 W, 14형은 67 W) 기본 67 W 어댑터에서 잘못된 저출력 경고가 뜨지 않도록 했습니다.

### 조정
- MacHelper 실행 중에 손쉬운 사용 권한을 허용해도 시스템 알림 직후, 앱이 활성화될 때, 그리고 10초마다 확인해 감지합니다. 적용을 위해 재시작이 필요한 경우 **조정**에 **재시작 필요** 표시와 **MacHelper 재시작** 버튼이 나타나며 `machelper tweaks status`는 `accessibilityRestartRequired`를 보고합니다.
- macOS 27 이상에서는 권한 요청 버튼과 CLI 안내가 시스템 설정에서 바뀐 목록 이름인 **기기 제어 및 데이터 접근**을 사용합니다(이전 버전은 **손쉬운 사용**).
- **언어** 변경이나 **설정 가져오기** 이후 앱을 다시 열 때 MacHelper가 완전히 종료될 때까지 기다린 뒤 재실행합니다.
