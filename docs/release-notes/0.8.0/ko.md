MacHelper가 사전 안내와 플로팅 시스템 설정 가이드를 갖춘 **권한** 설정 탭을 추가하고, 메뉴 막대 아이콘 숨기기 및 Dock 아이콘 메뉴 탐색을 지원합니다. 또한 **동작** 메뉴와 `⌘F` 검색이 되는 사용자화 가능 도구 막대를 도입했으며, 메인 윈도우 최소 크기를 화면 절반(`720 × 520`)으로 줄이고 **제거**와 **시동 항목**에서 `Delete` 키 동작 및 `.app` 드래그 선택을 지원합니다.

### 권한 안내
- **설정 → 권한** 탭을 추가해 현재 설정에 필요한 항목, 선택 사항, 지금 필요하지 않은 항목으로 구분하고 각 권한의 실시간 상태, **사용하는 기능**, **없으면** 빠지는 동작, **절대 접근하지 않는 것**, 원클릭 동작 버튼을 제공합니다.
- Helper 설치, **손쉬운 사용**, **Finder 자동화**, **알림**에 대해 macOS 시스템 프롬프트가 뜨기 전에 다음에 나타날 화면과 절차를 먼저 설명하는 안내 시트를 추가했습니다.
- 수동 전환이나 승인을 위해 시스템 설정을 열면 포커스를 빼앗지 않는 플로팅 안내 창이 시스템 설정 옆에 함께 열리며(**전체 디스크 접근 권한**에서는 드래그 가능한 MacHelper 앱 아이콘 포함), 권한 허용이 감지되거나 MacHelper로 돌아오면 자동으로 닫힙니다.
- **환영 가이드**의 권한 단계(Helper부터 시작), Helper 경고 배너, 사이드바 Helper 상태, **최적화**, **디스크 분석**, **조정**, 알림 설정, **백그라운드 기록**, **자동 정리**, **설정 → Helper** 등 모든 권한 진입점을 이 흐름으로 통합했습니다. 기능이 켜져 있지만 에이전트가 등록되지 않은 경우 **다시 설정**을, 알림이 거부된 경우 **알림 설정 열기**를 제공합니다.
- **전체 디스크 접근 권한** 설명을 바로잡아 중복 파일을 찾거나 미리 볼 때만 이 Mac 내부에서 파일 내용을 읽는다고 명시했으며, 모든 권한 설명과 안내를 5개 언어(`es`, `ja`, `ko`, `zh-Hans`, `zh-Hant`)로 번역했습니다.

### Dock 및 메뉴 막대
- 현재 표시 중인 주요 페이지(**개요**, **모니터**, **최적화**, **디스크 분석**, **제거**)와 **설정…**으로 바로 이동할 수 있는 Dock 아이콘 메뉴를 추가했습니다.
- **설정 → 메뉴 막대** 상단에 **메뉴 막대에 MacHelper 표시** 스위치를 추가했습니다. 끄면 메뉴 막대 아이콘이 즉시 가려지고 열려 있던 패널이 닫히며, 앱에 계속 접근할 수 있도록 Dock 아이콘은 유지됩니다(**설정 → 일반**의 Dock 아이콘 숨김 옵션은 비활성화됨). 이 설정은 설정 백업에도 저장됩니다.
- 다른 앱이 전체 화면일 때 메뉴 막대 아이콘을 클릭하면 보이지 않는 스페이스에 패널이 열리던 문제를 수정해 현재 전체 화면 스페이스 위에 정상적으로 표시됩니다.

### 메뉴, 도구 막대 및 윈도우
- **보기**와 **윈도우** 사이에 **동작** 메뉴를 추가해 현재 페이지의 주요 동작과 새로 고침(`⌘R`)을 고정 위치에서 실행할 수 있습니다.
- 윈도우 도구 막대를 사용자화할 수 있게 하고(**보기 → 도구 막대 사용자화…**), **보기** 메뉴에 **도구 막대 보기**와 **사이드바 보기**를 추가했습니다. 페이지별 새로 고침과 **최적화** 버튼, 그리고 **최적화**·**디스크 분석**(가장 큰 파일)·**제거**(앱)·**시동 항목**의 검색 필드를 도구 막대로 옮겼으며 **편집 → 찾기…**(`⌘F`)로 바로 포커스할 수 있습니다.
- **보기** 메뉴에 중복되어 있던 **인터페이스 크게** 항목을 하나로 정리해 `⌘=`를 표시하고, Caps Lock이 켜져 있거나 숫자 키패드의 `⌘+`를 눌러도 동작하도록 했습니다.
- 메인 윈도우 최소 크기를 `980 × 640`에서 `720 × 520`(13형 MacBook Air 화면의 절반 너비)으로 줄이고 **개요**, **모니터**, **상태 점검**, **케이블**, **최적화**, **디스크 분석**, **제거**, **시동 항목**에 좁은 화면용 레이아웃과 스크롤 가능한 빈 상태 화면을 적용했습니다.
- **디스크 분석**에서 저장된 스캔 결과를 볼 때 반 화면 너비에서 창을 벗어나던 문제를 수정했고, Helper 경고 배너를 세부 영역 위에 띄워 화면을 밀어내지 않으면서도 VoiceOver가 계속 가장 먼저 읽도록 했습니다.

### 제거 및 시동 항목
- **제거**에서 선택한 앱이나 체크한 잔여 항목, 또는 **시동 항목**에서 제거 가능한 사용자 에이전트나 전환 가능한 시스템 데몬을 선택한 채 `Delete` 키를 누르면 해당 버튼과 동일한 조건에서 확인 대화상자가 열립니다.
- Finder에서 `.app` 번들을 **제거** 창으로 드래그하면 **앱** 탭으로 전환되고 일치하는 설치된 앱이 선택됩니다(DMG나 다운로드 폴더의 사본을 끌어다 놓아도 매칭됨). 응용 프로그램 폴더에 설치되지 않은 앱은 거부되며 탭 아래에 안내 문구가 표시됩니다.
