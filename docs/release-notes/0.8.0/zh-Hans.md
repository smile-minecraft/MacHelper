MacHelper 在设置中新增包含系统提示前说明与浮动系统设置指引的 **权限** 标签页，支持隐藏菜单栏图标并改由 Dock 图标菜单导航，新增 **操作** 菜单与支持 `⌘F` 搜索的可自定义工具栏，主窗口最小可缩至半屏（`720 × 520`），并在 **卸载** 与 **启动项** 中加入 `Delete` 键操作与拖入 `.app` 选中功能。

### 权限引导
- 在 **设置 → 权限** 按当前设置需要、可选与目前不需要分组列出各项权限，显示实时状态、**用于** 哪些功能、**没有它时** 会缺少什么、**绝不读取** 哪些内容，并提供一键操作按钮。
- 在 macOS 弹出系统询问前，先为 Helper 安装、**辅助功能**、**Finder 自动化** 与 **通知** 显示说明弹窗，提前告知接下来会出现的系统步骤再继续。
- 打开系统设置进行手动开关或批准时，旁侧会显示不抢占焦点的浮动指引窗口（**完全磁盘访问权限** 附带可拖动的 MacHelper App 图标），在检测到权限生效或切回 MacHelper 时自动关闭。
- 统一 **欢迎导览**（改为从 Helper 步骤开始）、Helper 警告横幅、侧边栏 Helper 状态、**一键优化**、**磁盘分析**、**调整**、**通知** 提醒、**后台记录**、**自动清理** 与 **设置 → Helper** 的权限入口；已开启功能但代理未注册时提供 **重新设置**，通知被拒绝时提供 **打开通知设置**。
- 修正 **完全磁盘访问权限** 的隐私说明，明确只有在本地查找重复文件或预览文件时才会读取文件内容；所有权限说明与指引均提供五种语言翻译（`es`、`ja`、`ko`、`zh-Hans`、`zh-Hant`）。

### Dock 与菜单栏
- 新增 Dock 图标菜单，可直接打开当前显示的常用页面（**概览**、**监控**、**一键优化**、**磁盘分析**、**卸载**）与 **设置…**。
- 在 **设置 → 菜单栏** 顶部新增 **在菜单栏中显示 MacHelper** 开关；关闭后会立即隐藏菜单栏图标并关闭面板，同时保持 Dock 图标显示（禁用 **设置 → 通用** 中会隐藏图标的 **Dock 图标** 选项）以便随时打开应用，设置备份也会保留此偏好。
- 修复在其他 App 处于全屏空间时点击菜单栏图标，面板打开在不可见桌面的问题，现可在当前全屏空间上方正常显示。

### 菜单、工具栏与窗口
- 在 **查看** 与 **窗口** 之间新增 **操作** 菜单，固定提供当前页面的主要操作与刷新（`⌘R`），切换页面时菜单项与快捷键位置保持不变。
- 窗口工具栏支持自定义（**查看 → 自定义工具栏…**），**查看** 菜单补充 **显示工具栏** 与 **显示边栏**；各页刷新按钮与 **一键优化** 操作移入工具栏，**一键优化**、**磁盘分析**（**最大文件** 标签页）、**卸载**（**App** 标签页）与 **启动项** 的搜索框也移至工具栏，并可通过 **编辑 → 查找…**（`⌘F`）聚焦。
- 移除 **查看** 菜单中重复的 **放大界面** 项目，菜单保留 `⌘=`，`⌘+` 在大写锁定开启或使用数字小键盘时同样生效。
- 主窗口最小尺寸由 `980 × 640` 放宽至 `720 × 520`（约 13 英寸 MacBook Air 半屏宽度），**概览**、**监控**、**健康检查**、**线材**、**一键优化**、**磁盘分析**、**卸载** 与 **启动项** 在窄宽下改用紧凑布局，空状态改为可滚动以免按钮被裁切。
- 修复 **磁盘分析** 在半屏宽度下显示已保存扫描结果时内容超出窗口的问题；Helper 警告横幅改为浮动在详情区域上方，不再把页面内容推出窗口外，且 VoiceOver 仍会优先朗读该提示。

### 卸载与启动项
- 在 **卸载** 中对选中的 App 或勾选的残留项目按下 `Delete` 键，或在 **启动项** 中对可移除的用户代理或可切换的系统守护进程按下 `Delete` 键时，会在与对应按钮相同的条件下打开确认弹窗。
- 从 Finder 将 `.app` 拖放到 **卸载** 窗口时，会自动切换到 **App** 标签页并选中对应的已安装 App（即使拖入来自 DMG 或下载文件夹的副本也能匹配）；若该 App 未安装在「应用程序」文件夹中，则会拒绝打开并在标签栏下方说明原因。
