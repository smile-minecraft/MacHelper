MacHelper は Hardened Runtime 下で **Finder オートメーション** の許可ダイアログが表示されず「続ける」を押しても反応しない問題を修正し、Finder・Mission Control・ウインドウボタン・除外アプリ一覧の各 **調整** 機能を修復しました。また、画面切り替えや **ワンクリック最適化** へ戻る際のアニメーションのガタつきと、スキャン中のファイルサイズ表示の不具合も修正しています。

### 権限と調整
- アプリに `com.apple.security.automation.apple-events` エンタイトルメントを追加し、リリース時の Sparkle 再署名後も維持されるようにしました。これにより **Finder オートメーション** 説明シートで「続ける」を押しても反応しない問題と「Finder で新規ファイル作成」ショートカットの失敗を解消しています。
- Finder オートメーション要求フローを改善し、Finder が未起動の場合はバックグラウンドで起動してから再確認し、以前拒否された場合や macOS がダイアログを表示しない場合は **プライバシーとセキュリティ → オートメーション** を開くようにしました。「許可しない」を選んだ場合はその選択を尊重します。
- Finder でファイルを右クリックして **新規ファイル** を選んだ際にファイルパスが渡されて失敗する不具合を修正し、現在ウインドウが開いているフォルダに作成するようにしました。
- Finder メニューの URL ハンドラを起動処理中に登録して調整エンジン開始までキュー保持するよう変更し、Finder メニューから MacHelper を起動した際の最初の操作が失われないようにしました。
- **Mission Control** のオーバーレイボタンが非アクティブ時に 1 回目のクリックに反応しない問題を修正し、信号機ボタンの判定範囲を上部 `30 pt` から `56 pt` に広げて高さのあるツールバーウインドウにも対応しました。
- **調整** 画面の除外アプリ一覧フィールドが 1 文字入力ごとに保存してカンマを消してしまう問題を修正し、編集終了時に保存して CLI と同じ解析ルールを共有するようにしました。
- Finder オートメーションや Finder 機能拡張が必要な調整項目の横に直接許可ボタンを追加し、MacHelper がアクティブになった際に Finder オートメーション状態を再確認するようにしました。

### インターフェースとスキャン表示
- **ワンクリック最適化**・**ディスク分析**・**アンインストール** のページ状態遷移で旧状態を即座に取り除き小数倍スケールを外すことで、**ワンクリック最適化** の開始画面へ戻る際や状態切り替え時のガタつきと文字のにじみを解消しました。
- ページ幅をレイアウトパス中に直接渡すよう変更してサイドバー切り替え時の幅ジャンプをなくし、**ディスク分析** で保存済みスキャンを復元する際の二重アニメーションを削除しました。
- サイズ表記を共通フォーマッタへ統一し、0 バイトを `"Zero KB"` ではなく `"0 bytes"` と表示するほか、負値・範囲外値のクランプ、ロケールに応じた小数点表示、非有限レート値の安全な処理に対応しました。
- **ディスク分析** の再スキャン時に前回の合計が残ったり、複数の進捗ポーリングが上書きし合って数値が前後したりする問題を修正し、スキャンごとに単一のポーリングと単調増加のカウンタ表示に統一しました。
- **アンインストール** でアプリを切り替えた直後に前のアプリの残留ファイルと選択サイズが表示される問題、および遅延した読み込み完了でスピナーが止まらなくなる問題を修正しました。
