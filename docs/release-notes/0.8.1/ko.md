MacHelper가 Hardened Runtime 환경에서 **Finder 자동화** 권한 알림이 표시되지 않고 ‘계속’을 눌러도 반응하지 않던 문제를 수정하고, Finder·Mission Control·윈도우 버튼·제외 앱 목록 등 여러 **조정** 기능을 바로잡았습니다. 또한 화면 전환 및 **원클릭 최적화**로 돌아갈 때의 애니메이션 떨림과 스캔 중 파일 크기 표시 오류를 수정했습니다.

### 권한 및 조정
- 앱에 `com.apple.security.automation.apple-events` 인타이틀먼트를 추가하고 릴리스 빌드에서 Sparkle 재서명 후에도 유지되도록 하여, **Finder 자동화** 안내 시트에서 ‘계속’을 눌러도 아무 반응이 없던 문제와 ‘Finder에서 새 파일 만들기’ 단축키 실패를 해결했습니다.
- Finder 자동화 요청 흐름을 개선해 Finder가 실행 중이 아니면 백그라운드에서 먼저 실행한 뒤 요청하고, 이전에 거부되었거나 macOS가 프롬프트를 띄우지 않으면 **개인정보 보호 및 보안 → 자동화**를 열며, ‘허용 안 함’을 선택한 경우 그 결정을 존중합니다.
- Finder에서 파일을 오른쪽 클릭해 **새 파일**을 선택할 때 파일 경로가 전달되어 실패하던 문제를 수정해 현재 윈도우가 표시 중인 폴더에 파일이 생성되도록 했습니다.
- Finder 메뉴 URL 핸들러를 앱 실행 단계에서 미리 등록하고 조정 엔진이 시작될 때까지 요청을 대기열에 보관해, Finder 메뉴 클릭으로 MacHelper가 실행될 때 첫 동작이 누락되지 않도록 했습니다.
- MacHelper가 비활성 상태일 때 **Mission Control** 오버레이 버튼이 첫 클릭을 무시하던 문제를 수정했고, 도구 막대가 높은 윈도우를 위해 신호등 버튼 상단 판정 영역을 `30 pt`에서 `56 pt`로 넓혔습니다.
- **조정** 페이지의 제외 앱 목록 입력란이 한 글자 입력할 때마다 저장해 쉼표가 사라지던 문제를 수정해 편집이 끝날 때 저장하도록 바꾸고 CLI와 동일한 파싱 규칙을 공유합니다.
- Finder 자동화 또는 Finder 확장 프로그램이 필요한 조정 항목 옆에 바로 권한을 열 수 있는 버튼을 추가했고, MacHelper가 활성화될 때 Finder 자동화 상태를 다시 확인합니다.

### 인터페이스 및 스캔 표시
- **원클릭 최적화**, **디스크 분석**, **제거**의 전체 화면 상태 전환에서 이전 상태를 즉시 제거하고 소수 배율 축소 효과를 없애, **원클릭 최적화** 시작 화면으로 돌아가거나 상태를 전환할 때의 버벅임과 텍스트 흔들림을 해소했습니다.
- 페이지 콘텐츠 너비를 레이아웃 단계에서 즉시 전달해 사이드바 전환 시 넓은 레이아웃에서 좁은 레이아웃으로 튀던 현상을 없앴고, **디스크 분석**에서 저장된 스캔을 복원할 때의 중복 애니메이션을 제거했습니다.
- 크기 표기를 통합 포매터로 교체해 0바이트를 `"Zero KB"` 대신 `"0 bytes"`로 표시하고, 음수·범위 초과 값 클램핑, 시스템 로캘 소수점 적용, 비유한 속도 값의 안전한 처리를 지원합니다.
- **디스크 분석** 재스캔 시 이전 스캔 합계가 남거나 겹친 진행 폴링으로 숫자가 오르내리던 문제를 수정해 스캔당 하나의 폴링만 유지하고 카운터가 단조 증가하도록 했습니다.
- **제거**에서 앱을 전환할 때 이전 앱의 잔여 항목과 선택 크기가 잠시 표시되던 문제와 늦게 끝난 백그라운드 로드가 스피너를 멈추지 못하게 하던 문제를 수정했습니다.
