MacHelper 修复了 Hardened Runtime 下 **Finder 自动化** 权限弹窗无法出现、点击“继续”无响应的问题，修复了 Finder、Mission Control、窗口按钮和排除列表等多项 **调整** 功能，消除了切换页面与返回 **一键优化** 时的动画抖动，并修正了扫描期间文件大小数字显示异常。

### 权限与调整
- 为应用补充 `com.apple.security.automation.apple-events` 权限配置并在发布重签 Sparkle 后保留该权限，修复点击 **Finder 自动化** 说明页“继续”无反应以及“在 Finder 中新建文件”快捷键失败的问题。
- 改进 Finder 自动化请求流程：若 Finder 未运行会先在后台启动再请求；若此前已拒绝或 macOS 未弹出提示，则打开 **隐私与安全性 → 自动化**；若本次点击“不允许”则尊重选择，不再强制跳转设置。
- 修复在 Finder 中右键文件选择 **新建文件** 时因传入文件路径而失败的问题，现会在当前窗口所在文件夹内创建文件。
- 将 Finder 菜单 URL 处理器提前至启动阶段注册并排队等待调整引擎就绪，从 Finder 右键菜单启动 MacHelper 时首次操作不再丢失。
- 修复 **Mission Control** 悬浮窗口按钮在 MacHelper 非活跃状态下首次点击无响应的问题，并将红绿灯按钮顶部命中区域从 `30 pt` 放宽至 `56 pt` 以适配更高的工具栏窗口。
- 修复 **调整** 页面排除应用列表输入框每输入一个字符就保存导致逗号被清除、只能填写一个应用的问题，改为结束编辑时保存并与 CLI 共用解析规则。
- 在需要对应权限的调整项旁直接提供 **允许 Finder 控制** 与 **开启 Finder 扩展** 按钮，并在切回 MacHelper 前台时重新检查 Finder 自动化状态。

### 界面与扫描显示
- **一键优化**、**磁盘分析** 与 **卸载** 的整页状态切换改为立即移除旧视图且不进行小数缩放，消除返回 **一键优化** 起始页或切换状态时的卡顿抖动与文字闪烁。
- 改为在布局阶段直接提供页面内容宽度，消除侧边栏切换页面时先宽后窄的跳动，并移除 **磁盘分析** 恢复历史扫描时的重复整页动画。
- 统一字节大小格式化逻辑，将 `0` 字节显示为 `0 bytes` 而非 `Zero KB`，对负值与超界值进行钳制，遵循系统区域小数点格式，并安全处理非有限速率值。
- 修复 **磁盘分析** 重新扫描时残留上次总量或旧进度轮询相互覆盖导致数字来回跳动的问题，改为每次扫描仅保留单一轮询且计数单调递增。
- 修复 **卸载** 切换应用时短暂显示上一个应用残留项和所选大小的问题，并防止过期的后台加载任务导致加载指示器卡住。
