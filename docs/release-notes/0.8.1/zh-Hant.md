MacHelper 修正 Hardened Runtime 下 **Finder 自動化** 權限提示無法彈出、按「繼續」沒有反應的問題，修復 Finder、Mission Control、視窗按鈕與排除清單等多項 **調整** 功能，消除切頁與返回 **一鍵優化** 時的動畫抖動，並修正掃描期間的檔案大小數字顯示異常。

### 權限與調整
- 為 App 加入 `com.apple.security.automation.apple-events` 權限描述並在發佈重簽 Sparkle 後保留該權限，修正點擊 **Finder 自動化** 說明頁「繼續」毫無反應及「在 Finder 中新增檔案」快速鍵失敗的問題。
- 改進 Finder 自動化要求流程：若 Finder 尚未啟動會先在背景開啟再詢問；若先前已拒絕或 macOS 未顯示提示則自動開啟 **隱私權與安全性 → 自動化**；若當次選擇「不允許」則尊重選擇不再強開設定。
- 修正對 Finder 中的檔案按右鍵選擇 **新增檔案** 時因送出檔案路徑而失敗的問題，現在會在目前視窗所在的資料夾中建立檔案。
- 將 Finder 選單 URL 處理程序提前至啟動階段安裝並暫存請求直到調整引擎就緒，從 Finder 右鍵選單喚起 MacHelper 時第一下操作不再遺失。
- 修正 **Mission Control** 浮動視窗按鈕在 MacHelper 非作用中時第一下點擊無反應的問題，並將紅綠燈按鈕頂部判定區由 `30 pt` 放寬至 `56 pt`，相容較高的工具列視窗。
- 修正 **調整** 頁面排除 App 清單欄位每打一字就存檔導致逗號消失、只能填一個 App 的問題，改為結束編輯時儲存並與 CLI 共用解析規則。
- 在需要權限的調整項目旁直接提供 **允許 Finder 控制** 與 **開啟 Finder 延伸功能** 按鈕，並在回到 MacHelper 前景時重新檢查 Finder 自動化狀態。

### 介面與掃描顯示
- **一鍵優化**、**磁碟分析** 與 **解除安裝** 的整頁狀態切換改為立即移除舊畫面且不做分數縮放，消除返回 **一鍵優化** 起始頁或切換狀態時的畫面抖動與文字閃爍。
- 改在佈局階段直接提供頁面寬度，消除側邊欄切換頁面時先寬後窄的排版跳動，並移除 **磁碟分析** 還原掃描時的重複整頁動畫。
- 統一檔案大小格式化邏輯，將 `0` 位元組改為顯示 `0 bytes` 而非 `Zero KB`，正確夾住負值與超界數值、依系統地區顯示小數點，並安全處理非有限速率值。
- 修正 **磁碟分析** 重新掃描時殘留前次總量或舊進度輪詢覆寫導致數字來回跳動的問題，改為每次掃描僅持有單一輪詢且計數只增不減。
- 修正 **解除安裝** 切換 App 時短暫顯示上一個 App 殘留項目與選取大小的問題，並避免過期的背景載入結果讓轉圈指示器卡住。
