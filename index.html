Features

Everything your Mac is doing.
And what to do about it.

Native SwiftUI, built for Apple Silicon. Light on the CPU, quiet in the menu bar, and it previews every change before it makes one.

A live view of every sensor, right in the menu bar.

CPU performance and efficiency cores, GPU, memory pressure, temperatures, fans, power, battery, disk and network, with live charts and per-minute history.

  • History for 1 hour, 24 hours or 7 days, with warning lines for memory and heat.
  • A menu bar panel with gauges, cores, history and the busiest processes.
  • Alerts for high CPU temperature, critical memory pressure and low disk space.

Monitor

One score for how your Mac is really doing.

The health score comes from the last hours of history, free space and background items, and it tells you what lowers it and what to do next.

  • Read-only security audit of Gatekeeper, FileVault, the firewall, SIP, automatic security updates and XProtect.
  • Startup items: your launch agents, all-users agents and system daemons, with the owning app and broken items marked.
  • The slime turns blue, yellow or red with your Mac's mood.
Health Check

See where the space went, then take it back.

A sunburst and a treemap of any folder: click a ring to jump straight into it. Then sort the largest files by kind and age.

  • Insights for big unused files and folders that keep growing.
  • Duplicates that understand APFS clones and hard links, so nothing is counted twice.
  • What changed since the last scan, plus a collector to send many items to the Trash at once.
Disk Analysis

Fan control that stays inside safe limits.

Leave fans on automatic, pin a fixed speed, or draw a temperature curve. A small signed Helper does the work, and it checks the signature of every caller.

  • Curves: quiet, balanced, performance or your own, plus an “only increase” mode.
  • Hard safety limits that no curve or profile can override.
  • Profiles that switch by the app that is running or the power source.

One click to clean, with a preview first.

Declarative cleaning rules sort every item by risk. Low-risk caches are deleted, medium and high risk go to the Trash, and protected paths are never touched.

  • Developer junk: Xcode data, simulator runtimes, package caches and project build folders such as node_modules.
  • A never-clean list, an operation log, maintenance tasks and scheduled auto-clean.
  • Homebrew updates for the apps you installed with Homebrew.

Uninstall apps, and everything they left behind.

MacHelper finds leftovers from bundle IDs, embedded helpers, entitlements, container metadata, launchd ownership, Homebrew zap lists and per-app rules.

  • Name-only matches are flagged for you to review, never removed blindly.
  • Orphans: leftovers of apps you already deleted.
  • Trash by default, so you can always change your mind.

AI agents & command line

Built for agents.
Safe for your files.

The machelper command ships inside the app. Every command has --json, stable exit codes and a preview mode, so Claude Code, Codex, OpenCode or any agent that runs shell commands can help with your Mac without guessing.

  • Preview by default

    Nothing changes until --yes is added. Removed items go to the Trash unless --permanent, and protected paths such as Keychains, Mail, Photos, ~/.ssh and ~/Documents can never be removed.

  • machelper report --jsonNEW

    One redacted diagnostic report of the whole Mac: health, resources, disk, security and background items. User names, home paths, host names, IP and MAC addresses are masked, and suggestedActions tells the agent which commands to preview next.

  • An agent skill and a guide

    machelper skill install claude or codex installs a skill that tells the agent to preview first and ask before applying. machelper guide is the overview any agent should read first.

Privacy & transparency

Your Mac’s data stays on your Mac.

MacHelper is local-first. It reads sensors and folders to help you, and keeps what it learns to itself.

Everything runs locally

Readings, history, scans and cleanup logs are stored on your Mac. The only network call by default is the update check.

No account, ever

No sign-in, no subscription and no license key. Download it, open it, done.

Open source and signed

MIT licensed, so you can read every line. Releases are signed with a Developer ID, notarized by Apple and published with checksums.

Optional telemetry

Off by default. Yours to turn on.

To help make MacHelper faster, you can choose to share anonymous usage and performance numbers. Nothing is sent unless you switch it on.

  • Opt-in only. It starts switched off, and turning it off stops it.
  • No personal data. No user names, host names, file names, file paths or file contents.
  • Inspectable. Settings shows the exact payload before anything leaves your Mac.

FAQ

Questions, answered.

Is there a free, open-source alternative to CleanMyMac or iStat Menus?

MacHelper is MIT licensed and covers cleanup, menu bar system monitoring, fan control, disk analysis and app uninstalling in one app, with no account and no subscription.

How do I control the fan speed of an Apple Silicon Mac?

Install MacHelper and set up its Helper, a small root daemon offered on first launch. Fans can then run automatically, at a fixed speed or on a temperature curve, with hard safety limits and profiles that switch by running app or power source.

How do I free up disk space on a Mac from the terminal?

Run brew install --cask smile-minecraft/tap/machelper, then machelper clean to preview and machelper clean --max-risk low --yes to clean only the low-risk items.

machelper insights ~ lists big unused files and folders that have grown, and machelper purge --path ~/Developer removes project build folders such as node_modules.

How do I completely uninstall a Mac app and its leftover files?

machelper uninstall "App Name" previews everything the app left behind; add --yes to move it to the Trash. machelper uninstall --orphans finds leftovers of apps that are already gone. The app has the same feature.

What data does MacHelper collect?

By default, nothing leaves your Mac except the update check. Readings, history and scan results stay local and no account is needed.

Anonymous usage and performance telemetry is off by default. If you opt in, it never includes personal data, user names, host names or file paths, and Settings shows the exact payload.

How can an AI agent understand the state of my whole Mac?

machelper report --json produces one redacted diagnostic report covering health, resources, disk, security and background items. User names, home paths, host names, IP and MAC addresses are masked, and a suggestedActions list tells the agent which machelper commands to preview next.

Is it safe to let an AI agent run MacHelper?

Yes, with the skill installed: commands only preview unless --yes is given, the skill tells the agent to show the plan and get a clear yes first, items go to the Trash by default, and protected paths cannot be removed even with --yes.

Does MacHelper work on Intel Macs or older macOS?

No. MacHelper needs macOS 14 or later on an Apple Silicon Mac.
